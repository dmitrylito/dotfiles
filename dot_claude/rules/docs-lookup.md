# Documentation tools

Follow the current-documentation policy in shared-global.md, including for familiar
and routine usage. There is no familiarity-based exception.

- For Context7, resolve the library ID, then query its docs with the relevant
  version and question. Use official-site search/fetch if its content is missing,
  stale, or insufficient. Cite only content actually retrieved and read.
- Claude Code / Anthropic API questions may use the claude-code-guide agent or
  claude-api skill; they must still verify current official documentation.
- HubSpot platform questions may use HubSpotDev search-docs under the same rule.
